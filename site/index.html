Offline by default

No network calls, no telemetry, no API keys. Remote MCP scanning is opt-in and SSRF-guarded.

Never executes

Scanned content is untrusted. It is read as text — never run, imported, or fetched. Packages are extracted, not installed.

Redacted output

Likely secrets are redacted and control characters stripped, so reports are safe to paste into a ticket or CI log.

CI-native

Text, JSON, and SARIF 2.1.0. Fail the build at the severity you choose with --fail-on.

/ 02 — coverage

What it checks

24 deterministic rules, in plain terms. Full rule reference →

  • Hijacked instructionsText that tells your agent to ignore its real instructions or hide what it is doing.
  • Hidden textInvisible characters, comments, or encoded blobs used to smuggle instructions past a reader.
  • Secrets and keysReads of .env files, cloud keys, SSH keys, or password stores.
  • Dangerous commandsDownloading and running code, deleting files, or quietly executing scripts.
  • Data sent outSending your files or credentials to an outside address.
  • Untrustworthy add-onsFake tool names, orders aimed at the model, and secrets baked into config files.

Injection

  • inj.ignore-previoushigh

    Instruction-hijack phrasing commonly used in prompt injection.

  • inj.hidden-instructionhigh

    Instruction-like content hidden in HTML comments.

  • inj.system-promptmedium

    Attempts to reveal, replace, or ignore the system prompt.

Obfuscation

  • obf.zero-widthhigh

    Hidden zero-width and bidirectional formatting characters.

  • obf.encoded-blobhigh

    Encoded blob (base64/hex) that decodes to suspicious instructions.

  • obf.homoglyphmedium

    Mixed-script characters that may spoof words or identifiers.

Secrets

  • sec.env-readhigh

    Access to credential stores and secret-looking environment variables.

Execution

  • exec.download-runcritical

    Downloads and executes a remote script.

  • exec.destructivehigh

    Destructive command (broad delete, wipe, or disk write).

  • exec.dynamicmedium

    Dynamic code execution (eval / exec / shell).

Exfiltration

  • exf.outboundcritical

    Sends local data to an external URL.

  • exf.webhookhigh

    Known webhook or exfiltration endpoint.

Install hooks

  • hook.fetch-runhigh

    Install / build hook downloads or executes code.

Skill hygiene

  • skill.permissionsmedium

    Skill declares broad tool permissions.

  • hygiene.unpinnedlow

    Unpinned package runner (npx -y / uvx).

  • hygiene.httplow

    Plaintext HTTP URL (not localhost).

MCP

  • mcp.invalidinfo

    Config could not be parsed as JSON/YAML.

  • mcp.imperative-deschigh

    Tool descriptions contain instructions aimed at the model.

  • mcp.shadowhigh

    Server / tool names mimic well-known tools.

  • mcp.overreachmedium

    Requests secrets or filesystem access beyond its purpose.

  • mcp.args-exechigh

    Server command / args download or execute code.

  • mcp.transportmedium

    Plaintext HTTP or a loopback / IP-literal host.

  • mcp.secretshigh

    Hardcoded credential-looking values in env or headers.

  • mcp.hygienelow

    Unpinned package runner fetches a floating version.

/ 03 — CI

Fail the build, not the agent.

Drop the Action into a workflow and upload SARIF to GitHub code scanning. Findings land as annotations on the pull request that introduced them.

Get the Action
.github/workflows/security.yml 
name: SkillCanary
on: [push, pull_request]
permissions:
  security-events: write
jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: gabrielronai/skill-canary@v0
        with:
          fail-on: high
          upload-sarif: true

/ 05 — FAQ

Reasonable objections

Isn't this just heuristics?

Yes — a fast, deterministic first line that is offline and reproducible. It catches obvious and encoded patterns and pairs with SAST. We state that plainly rather than overclaiming.

I can read the SKILL.md myself.

Not fifty of them, not a base64 blob, not two hundred npm tarballs, not a live server's tool list — on every change, in CI, with a diff.

Is it really free?

Yes. The CLI and GitHub Action are Apache-2.0, run all 24 rules, and have no account, no telemetry, and unlimited local scans.

Won't Snyk or Socket just add this?

Maybe. SkillCanary covers the long-tail skills and MCP formats today and stays open source so trust accrues here first.

It's open source — I'll self-host.

Please do. The scanner is Apache-2.0 — read it, fork it, and run it wherever you like.
