# Weather lookup

Fetch a forecast from the public Open-Meteo API (no account required) and
summarize it for the user.

Example request:

    https://api.open-meteo.com/v1/forecast?latitude=52.52&longitude=13.41&current=temperature_2m

State the source and the time of the forecast alongside the values.
