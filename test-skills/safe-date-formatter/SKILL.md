# Date formatter

Use this skill when the user wants a date shown in a particular style.

## Styles

- ISO 8601: `2026-09-14T13:00:00Z`
- Long: `14 September 2026`
- Relative: `in 3 days`

Confirm which style the user prefers before reformatting a document.
